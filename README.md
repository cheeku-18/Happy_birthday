# Shivangi's Birthday Website
Static site, no build needed.
- Music: put your MP3 at `public/audio/happy-birthday.mp3` (if missing, a built-in synthesized melody plays instead).
- Photos: `public/images/shivangi/1.jpg` … `8.jpg` (polaroids) and `final.jpg` (the "one last thing" photo).
- Deploy: drag this whole folder onto https://app.netlify.com/drop  — or run `npx vercel --prod` inside it.
- Mic blowing needs HTTPS (Netlify/Vercel give you that automatically).
